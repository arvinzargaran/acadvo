Pathfinder — AI Academic Advisor Platform

Stack: FastAPI (Python) + React (Vite) + PostgreSQL + Google Gemini 2.5 Flash
Theme: Dark-mode SPA with purple/blue gradient accents, Tailwind CSS

---

WHAT IT DOES

Pathfinder is an AI-powered academic planning platform for Canadian university students. It tracks degree progress, plans courses semester-by-semester, manages career targets, and provides an AI advisor that can take actions (create courses, flag risks, build timelines) — not just chat.

ARCHITECTURE

BACKEND (FastAPI + SQLAlchemy + Gemini)

Database Models (PostgreSQL, async SQLAlchemy):

- User — email, password, university, program, start_year, expected_graduation_year, country, city, career_target, onboarding_complete
- DegreeRequirement — bucket_name, credits_required, description, notes (e.g. "Science Breadth: 6 credits")
- Course — course_code, course_name, credit_value, status (completed/in_progress/planned/not_scheduled), term, grade, requirement_bucket_id, credential_id
- Credential — name, description, total_credits_required (e.g. a minor or certificate)
- Project — name, description, priority (1-3), status (not_started/in_progress/deployed/interview_ready), tech_stack, repo_url, live_url, hard_deadline, product_framing
- Milestone — title, description, target_date, completed_at, status (pending/in_progress/complete/overdue), order_index
- CareerTarget — company_name, role_type, location, status (researching/applied/interviewing/offer/rejected), target_term, notes
- TimelineEvent — title, description, event_date, category (deadline/milestone/goal/co_op/academic), is_hard_deadline
- Conversation — title, is_onboarding, context_snapshot (JSONB)
- Message — role (user/assistant), content, tool_calls (JSONB array)
- AISuggestion — suggestion_type (course/project/career/schedule/risk_flag), content, severity (low/medium/high), accepted
- CourseRecommendation — semester, course_code, course_name, credits, requirement_bucket, reasoning, career_relevance, prerequisite_notes, priority, accepted, dismissed

Services:

- Auth — JWT tokens (access 30min, refresh 7day), bcrypt password hashing, refresh token rotation
- Degree — Credit completion calculation per bucket, overall percentage
- Course Recommendation — Gemini + Google Search grounding to search real university catalogs, generate personalized recommendations based on degree gaps + career goals
- Semester Plan — Full AI-powered semester-by-semester course plan from now to graduation. Considers prerequisites, workload balance (max 5 courses/semester), career alignment. Post-processes to strip past/current semesters and cap course counts.
- Document Parser — Gemini multimodal: upload PDF/image of degree checklist, extracts requirements + courses as structured JSON
- Weekly Summary — AI-generated progress summary with risks and next steps
- Resume Review — Upload resume PDF/image, Gemini returns score, strengths, improvements, ATS tips

AI System (Gemini 2.5 Flash):

- System Prompt (context.py): Builds comprehensive context from all user data (profile, degree progress, projects, career targets, upcoming events). Sets conversation mode: ONBOARDING, CHECK-IN, DEEP DIVE, or PLANNING.

- 15 Tool Declarations (tools.py): The AI can take actions:
  1. get_degree_summary — query degree progress
  2. suggest_courses — get course suggestions for a semester
  3. add_course — add a course to the plan
  4. update_course_status — change course status/grade
  5. create_project — create project with milestones
  6. update_milestone_status — update milestone status
  7. add_career_target — add target company
  8. update_career_target — update career target status
  9. flag_risk — create AI suggestion (risk flag)
  10. generate_timeline — create timeline events in bulk
  11. update_user_profile — save profile fields (used in onboarding)
  12. search_course_recommendations — web search for course recommendations
  13. search_and_recommend_courses — search catalog + AI recommend
  14. add_degree_requirement — create requirement bucket
  15. generate_semester_plan — full semester-by-semester plan

- Tool Executor (tool_executor.py): Maps tool names to async handlers that hit the database. Includes a university domain mapping (25 Canadian universities) for site-scoped Google Search.

- Conversation Loop (conversation.py): Send message -> build context -> call Gemini -> execute tool calls (up to 10 rounds) -> feed results back -> save final response with tool_calls array.

- Google Search Grounding: Uses google_search tool for real-time course catalog searches from actual university websites.

KEY FLOWS

Onboarding Flow:
  Register -> Redirected to /onboarding -> 6-step form (profile, degree requirements, courses, projects, career targets) -> All data saved via API -> onboarding_complete set to true -> Redirect to dashboard

AI Conversation Flow:
  User sends message -> System prompt built with full user context (degree, projects, career, deadlines) -> Gemini called with 15 available tools -> Tool calls executed (actual DB writes: create courses, flag risks, add targets, etc.) -> Results fed back to Gemini for next round (up to 10 rounds) -> Final response returned with tool call summaries displayed inline

Semester Planning Flow:
  User clicks "Generate AI Plan" -> Backend gathers all context (completed courses, in-progress, planned, requirement gaps, career targets, graduation year) -> Gemini + Google Search builds semester-by-semester plan using real university catalog -> Post-processed (strip past/current semesters, cap 5 courses per semester, remove duplicates) -> User reviews plan with reasoning for each course -> "Apply Plan" saves all new courses as planned status

Career Planning Flow:
  Empty state -> "Build My Career Plan" opens full-screen AI advisor -> AI suggests target companies, creates career targets, builds application timeline -> User tracks applications through Kanban pipeline (Researching -> Applied -> Interviewing -> Offer/Rejected) -> Upload resume for AI review with actionable feedback

Document Import Flow:
  Upload PDF/image/Excel -> Gemini multimodal extraction -> Structured JSON (requirements + courses) -> User reviews and edits in table UI -> Confirm saves all data to database

Course Recommendation Flow:
  Select target semester -> AI searches university catalog via Google Search grounding -> Returns 4-6 recommendations with reasoning, career relevance, prerequisites -> User accepts (adds to degree plan) or dismisses

TECH DETAILS

Backend:
  - Python 3.11+
  - FastAPI with async endpoints
  - SQLAlchemy 2.0 (async engine + sessions)
  - PostgreSQL database
  - Alembic for migrations
  - Pydantic v2 for request/response schemas
  - bcrypt for password hashing
  - JWT (HS256) for authentication with refresh token rotation

Frontend:
  - React 18
  - Vite build tool
  - Tailwind CSS (dark theme with custom color palette: dark-900 through dark-400, primary-500/600, purple/blue gradients)
  - Axios for HTTP with interceptors
  - React Router v6 with protected routes

AI:
  - Google Gemini 2.5 Flash model
  - Function calling with 15 custom tools
  - Google Search grounding for real-time university catalog search
  - Multimodal input (PDF, images) for document parsing and resume review
  - Context-aware system prompts built from full user data
  - Multi-turn tool execution loop (up to 10 rounds per message)

File Support:
  - PDF, PNG, JPEG, WebP, Excel (.xlsx/.xls), CSV
  - Max 10MB per upload
  - Used for: degree document parsing, resume review
